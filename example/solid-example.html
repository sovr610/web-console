💎 Solid.js + WebConsole

Solid.js fine-grained reactive wrapper demo

Solid.js uses JSX compilation for optimal performance. This demo uses the vanilla WebConsole to showcase the patterns the compiled <WebConsole /> Solid wrapper provides — signals, effects, memos, and resources. Build the real component with npm run build:solid.
