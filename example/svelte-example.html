🔥 Svelte + WebConsole

Svelte component wrapper demo

Svelte is a compiler — components must be built before they run in the browser. This demo uses the vanilla WebConsole to showcase the patterns the compiled <WebConsole /> Svelte wrapper provides (reactive props, lifecycle, event dispatching). Build the real component with npm run build:svelte.
