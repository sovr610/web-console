🅱 Angular + WebConsole

Angular 18 component wrapper demo

Since Angular requires a full build pipeline (AOT compilation, zones, etc.) it can't run from a plain HTML file like React or Vue. This example demonstrates using the vanilla WebConsole class directly — the same class the Angular wrapper delegates to — with UI patterns that match how you'd interact with it in an Angular app.
In a real Angular project:

import { WebConsoleComponent } from 'web-console/angular';

Template: <app-web-console [containerId]="'my-console'" [visible]="true" (ready)="onReady($event)"></app-web-console>

The component handles ngOnInit → create instance, ngOnDestroy → destroy, and exposes show(), hide(), toggle(), clearConsole(), addCustomTab(), addCustomMessage().

Building the Angular wrapper:
npm run build:angular — produces dist/angular-bundle.js (UMD)

In your Angular project, import the module:
imports: [WebConsoleModule]

The wrapper handles lifecycle automatically. This demo page simulates the same behaviour using the vanilla class directly.
